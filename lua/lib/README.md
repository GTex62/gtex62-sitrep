# lua/lib

Thin local compatibility/helper layer, mirroring the role
[`gtex62-osa/lua/lib`](../../../gtex62-osa/lua/lib/weather_codes.lua) plays for
OSA (a lookup table not worth promoting to the engine).

Empty for now. SitRep has no compatibility helpers yet; this directory exists
so future ones (e.g. status-code lookup tables for pfSense/Pi-hole/AP states)
have a conventional home instead of drifting into `lua/suite/`.
